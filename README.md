# 📧 Email Writer Project

## 🔹 Overview

The Email Writer Project is a full-stack web application designed to generate professional emails based on user input. It helps users save time by automating email drafting using a clean frontend and a powerful backend.

---

## 🔹 Tech Stack

* **Frontend:** React (Vite)
* **Backend:** Spring Boot
* **API Communication:** REST APIs
* **Tools:** Git, VS Code , Intellij Ideapad

---

## 🔹 Features

* ✨ Generate emails dynamically based on user input
* ⚡ Fast and responsive frontend
* 🔗 Seamless integration between frontend and backend


---

## 🔹 Project Structure

```
email-writer-project/
 ├── email-writer-frontend/
 ├── email-writer-backend/
```

---

## 🔹 How to Run the Project

### 1️⃣ Clone the Repository

```
git clone https://github.com/RishavSyal/email-writer-project.git
```

---

### 2️⃣ Run Backend (Spring Boot)

```
cd email-writer-backend
mvn spring-boot:run
```

---

### 3️⃣ Run Frontend (React)

```
cd email-writer-frontend
npm install
npm run dev
```

---

## 🔹 Usage

1. Start backend server
2. Run frontend
3. Enter input → Generate email
